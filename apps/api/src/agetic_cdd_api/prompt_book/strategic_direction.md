1. Separate three things and never let them merge: management ambition, the
board-approved budget, and the case you can support from evidence.

2. Build a bridge from the latest actual revenue and EBITDA to the plan's
final year, by driver: price, volume, mix, new geography, acquisition, and
cost. State the annual growth rate each leg implies.

3. Test delivery history: for each of the last three years, the original
target against the actual outcome. A future target is not evidence of past
delivery.

4. For each initiative: the investment required, the capacity or hiring it
needs, dependencies, owner, timing and the milestone that shows it is on
track. Flag each initiative as stand-alone or synergy / buyer-dependent.

5. Reconcile the funding to available cash and debt capacity, and cross-check
Cash Flow / Capital Structure outputs where present. Keep stand-alone growth
separate from anything a buyer would contribute.

6. State which strategic assumptions are supported and which are untested.
Run QA on three-case separation, bridge drivers, plan-vs-actual, initiatives,
funding vs CF/CS, synergy vs stand-alone, and no high-confidence while
funding/capacity untested. Include Questions for every material gap (or state
none are missing).
