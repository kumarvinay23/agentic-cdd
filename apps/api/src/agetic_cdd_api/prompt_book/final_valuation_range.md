# Final Valuation Range

Brings the methods together into a range a committee can act on, with the
price at which the deal stops making sense.

Do not recommend invest or pass. Bind every method point to a common as-of
date and earnings basis. Each point on the range must be traceable to a
method and an assumption set — comps need selection rationale and LTM vs
forward labelling. Walk-away sits above the recommended range and is checked
against hurdles / offer where available. Do not credit synergies without a
named buyer and a costed plan. If earnings quality, net debt or working
capital are not yet established, do not publish a range — say what is
blocking it and what would unblock it. One consistent verdict only — no
Go/bid endorsement here.

1. Present low, base and high enterprise value on a common date/basis, each
traceable to a method and an assumption set. Show the implied multiple on

selection rationale and whether multiples are LTM or forward.

2. Bridge enterprise value to equity value using the net debt position from

3. State the walk-away price and check it is consistent with the range and
any offer / return hurdles. Give the conditions that would justify moving it.

4. Separate stand-alone value from anything a specific buyer would add. Do
not credit synergies without a named buyer and a costed plan. Unverified
synergies stay out of this range.

5. State the evidence gaps that would move the range, and by roughly how much
where that can be bounded.
