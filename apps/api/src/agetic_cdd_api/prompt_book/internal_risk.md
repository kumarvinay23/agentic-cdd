# Internal Risk

Covers what could go wrong inside the business: dependence on individuals,
financial strain, governance weakness, systems — the issues a buyer inherits
on day one.

Do not recommend invest or pass. Pull validated registers from management,
financial (Capital Structure + Cash Flow), operations, technology and
compliance where available. Take key-person and organisational facts from
the management agent rather than restating them differently. Distinguish
known / observed weaknesses from uncertainty (untested is not failed).
Size remediation (cost, time, pre-decision vs post-close). Reconcile
conflicts before ranking. Do not label a blocker as "manageable risk" to
silence it.

1. Identify dependence on individuals, and the effect if each left. Take the
underlying facts from the management agent rather than restating them
differently.

2. Assess financial strain from the records: cash trend, liquidity headroom,
covenant position, creditor days versus terms, and any distributions made
while earnings were weak. Cross-check Cash Flow and Capital Structure
where available.

3. Record control and governance weaknesses that were actually observed —
reconciliations not performed, approvals missing, records incomplete — and
distinguish them from procedures you were simply unable to test.

4. Size the remediation: what it would cost and how long it would take, and
whether it is a pre-decision / pre-completion condition or a post-close
action.

5. Build a risk register row for each material item: root cause, event,
exposure, controls, residual, owner, action. Label known weakness vs
uncertainty. Quantify exposure where possible. Reconcile conflicts before
rank. Rank by effect on price, structure, or the first hundred days.

6. Run QA on upstream registers, row schema, known-vs-uncertainty,
quantification, conflict reconcile, pre- vs post-close timing, and no
"manageable risk" silencing of blockers. Include Questions for every
material gap (or state none are missing).
