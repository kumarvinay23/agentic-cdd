# Agentic CDD Web (Next.js)

DiligenceIQ-identical layout · **Agentic CDD** branding.

## Setup

```bash
cd apps/web
cp .env.example .env.local
npm install
```

## Run

```bash
npm run dev
```

- Sign in: [http://127.0.0.1:3000/login](http://127.0.0.1:3000/login)
- Status: [http://127.0.0.1:3000/status](http://127.0.0.1:3000/status)

Requires API on port **4600** for `/status` health check.
